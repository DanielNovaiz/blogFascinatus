1. Code Skills (Desenvolvimento)
Habilidades para gerar, refatorar e otimizar código.
Exemplos:

code-generation: Gerar código novo baseado em requisitos
refactoring: Melhorar qualidade do código existente
testing: Criar testes automatizados
documentation: Gerar documentação técnica
debug: Diagnosticar e corrigir bugs

Melhor Prática: Sempre especifique a linguagem de programação e o contexto do projeto (framework, padrão arquitetural).
2. Reasoning Skills (Raciocínio)
Habilidades para análise profunda e tomada de decisão.
Exemplos:

architectural-analysis: Analisar decisões arquiteturais
performance-analysis: Avaliar desempenho de código
security-review: Identificar vulnerabilidades
cost-optimization: Otimizar recursos
trade-off-analysis: Avaliar alternativas

Melhor Prática: Sempre justifique as recomendações com dados e contexto.
3. Integration Skills (Integração)
Habilidades para conectar sistemas e ferramentas.
Exemplos:

git-integration: Operações com repositório
api-integration: Trabalhar com APIs externas
database-operations: CRUD e otimizações
deployment: CI/CD e deployment
monitoring: Observabilidade e alertas

Melhor Prática: Sempre inclua tratamento de erros e fallback strategies.
4. Documentation Skills (Documentação)
Habilidades para criar documentação clara e útil.
Exemplos:

api-documentation: Documentar APIs
architecture-documentation: Documentar design de sistema
user-guide-creation: Criar guias para usuários
readme-generation: Gerar READMEs
changelog-creation: Manter histórico de mudanças

Melhor Prática: Use exemplos reais e mantenha a documentação atualizada.
